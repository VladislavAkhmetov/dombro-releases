# dombro Releases

Official binaries and updates for **dombro** — a serene local-first browser and workspace.

## Downloads

Download the latest version from [Releases](https://github.com/VladislavAkhmetov/dombro-releases/releases/latest):

* **`dombro-Setup-<version>.exe`** — Standard Windows installer with background auto-updates.
* **`dombro-<version>-Portable.exe`** — Single standalone executable. No installation required.

## Windows SmartScreen Note

Builds are currently distributed without a paid code signing certificate. On first launch:

1. Click **More info**.
2. Click **Run anyway**.

## System Requirements

* Windows 10 / 11 (64-bit)
